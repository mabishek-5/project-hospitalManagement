# 🏥 Hospital Management System

A modern web-based Hospital Management System designed to simplify and organize hospital operations through a centralized digital platform.

The system provides an easy-to-use interface for managing hospital activities such as patients, doctors, appointments, and medical records.

---

## 📌 Project Overview

The Hospital Management System is developed to reduce manual work and provide a structured way to manage hospital-related information.

The application provides a dashboard-based interface where hospital-related data can be accessed and managed efficiently.

---

## ✨ Features

- 🏥 Hospital Dashboard
- 👨‍⚕️ Doctor Management
- 🧑‍⚕️ Patient Management
- 📅 Appointment Management
- 📋 Medical Records Management
- 🔍 Easy navigation
- 📊 Organized data presentation
- 💻 Responsive web interface
- 🗄️ Database integration using Supabase

---

## 🛠️ Technologies Used

- **Frontend:** React / TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Database:** Supabase
- **Package Manager:** npm
- **Version Control:** Git & GitHub

## 🚀 Installation and Setup
1. Clone the repository
git clone https://github.com/YOUR-USERNAME/project-hospitalManagement.git
2. Open the project directory
cd project-hospitalManagement

Since the application is currently inside the project folder:

cd project
3. Install dependencies
npm install
4. Start the development server
npm run dev
5. Open the application

Open the URL displayed in the terminal, usually:

http://localhost:5173
## 🗄️ Database

The project uses Supabase for database-related functionality.

Database migration files are available in:

supabase/migrations/

Environment variables should be configured locally using a .env file.

⚠️ Never upload passwords, API secrets, private keys, or other sensitive credentials to GitHub.
